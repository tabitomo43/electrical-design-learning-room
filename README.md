# Electrical Design Learning Room

宇宙機・人工衛星分野の電気設計を学ぶための学習室です。  
質問、用語、設計メモ、缶サット製作の進捗を GitHub 上で整理し、あとから振り返りやすい形で残します。

## 目的

- 宇宙・人工衛星・電気設計に関する疑問を記録する
- 回答や調査結果を、あとから復習しやすい形でまとめる
- 知らない単語や略語を用語集として蓄積する
- 缶サット製作を通じて、定義、設計、製作、試験、改善の流れを経験する
- issue、branch、pull request を使って学習と製作の進捗を管理する

## 管理する内容

| 領域 | 内容 |
|---|---|
| 質問ログ | 宇宙、人工衛星、電気設計、部品、試験、規格などの質問と回答 |
| 用語集 | EPS、OBC、ADCS、レギュレータなどの用語と意味 |
| 学習ロードマップ | 人工衛星の電気設計を学ぶ順番と到達目標 |
| 缶サット製作 | ミッション定義、システム設計、電気設計、製作、試験 |
| GitHub 運用 | issue、branch、pull request、レビュー、マージ後の更新 |

## 最初の実践テーマ

最初の実践テーマは缶サット製作です。

1. ミッションを定義する
2. システム構成を整理する
3. 電源、制御、通信、センサの関係を設計する
4. 部品を選定する
5. 試作・製作する
6. 単体試験と統合試験を行う
7. 結果を振り返り、次の設計に反映する

## GitHub 運用ルール

- 1つの issue は、できるだけ小さな学習・調査・作業単位にする
- 変更は branch を切って進める
- pull request には、背景、変更内容、確認観点、次の作業を書く
- マージ後は README、docs、issue の状態を更新する
- 公開リポジトリに社名・所属名は載せない
